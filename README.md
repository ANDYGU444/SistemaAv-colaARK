# 🐔 Sistema Avícola - App Móvil

Sistema completo de gestión para granjas avícolas, optimizado como Progressive Web App (PWA).

## 📱 Características

- ✅ **Gestión completa** de transacciones, producción e inventario
- ✅ **Backup seguro** con exportación/importación de datos
- ✅ **Funciona offline** - Service Worker con cache inteligente
- ✅ **Instalable** como app nativa en Android/iOS
- ✅ **100% Responsive** - Optimizado para móviles
- ✅ **Seguro** - Validación y sanitización de datos

## 🚀 Instalación como App

### Android
1. Abre [https://tusuario.github.io/sistema-avicola-mobile](https://tusuario.github.io/sistema-avicola-mobile)
2. Toca el menú (⋮) → "Agregar a la pantalla de inicio"
3. Confirma la instalación

### iOS
1. Abre en Safari
2. Toca el icono de compartir (📤)
3. Selecciona "Agregar a pantalla de inicio"
4. Confirma la instalación

## 📊 Módulos Incluidos

- **Transacciones**: Control de ingresos y gastos
- **Producción**: Registro diario de huevos por cubículo  
- **Inventario**: Gestión de alimentos y materiales
- **Compradores**: Administración de clientes
- **Backup**: Exportación/importación segura

## 🛠 Tecnologías

- HTML5, CSS3, JavaScript vanilla
- PWA (Service Worker, Manifest)
- LocalStorage para persistencia de datos
- Font Awesome para iconos
- Diseño mobile-first
